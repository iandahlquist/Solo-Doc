# Solo-Doc
Getting Started: VSCode and GitHub Desktop
    A beginner's guide to basic web-publishing workflow. 
    Basic editor, a single-source repository, a live webpage, and adding collaborators.
## 1. Install an Editor
Install **Visual Studio Code** 
Use the left hand menu to find the extension tab
    Search for **Markdown All in One** in the extension menu and install
    Search for **Quarto** in the extension menu and install 
VScode (Visual Studio Code) is where you'll write and edit your files
    Each extension adds formatting shortcuts and visual feedback

## 2. Log On to GitHub
Create a free GitHub account at **https://github.com/join**
Install the **GitHub Desktop** app onto your device 
    Make sure to log in!
GitHub will host your repository online for you and your collaborators to access. 
GitHub Desktop provides an interface for Git actions rather than typing commands out fully
It will be important to keep track of your GitHub account
    **DONT LOSE YOUR PASSWORD**
