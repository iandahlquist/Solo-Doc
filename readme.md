# Solo-Doc
Getting Started: VSCode and GitHub Desktop
    A beginner's guide to basic web-publishing workflow. 
    Basic editor, a single-source repository, a live webpage, and adding collaborators.
## 1. Install an Editor
Install **Visual Studio Code**. Click [HERE](https://code.visualstudio.com/download?_exp_download=fb315fc982).
Use the left hand menu to find the extension tab.
    Search for **Markdown All in One** in the extension menu and install.
    Search for **Quarto** in the extension menu and install.
VScode (Visual Studio Code) is where you'll write and edit your files.
    Each extension adds formatting shortcuts and visual feedback.

## 2. Log On to GitHub
Create a free GitHub account [HERE](https://github.com/join).
Install the **GitHub Desktop** app onto your device.
    Make sure to log in!
GitHub will host your repository online for you and your collaborators to access. 
GitHub Desktop provides an interface for Git actions rather than typing commands out fully.
It will be important to keep track of your GitHub account.
    **DONT LOSE YOUR PASSWORD**

## 3. Create a Repository
In GitHub create a new **PUBLIC** repository. Anyone in the world can now view this repository. Inside of this newly created repository, create a file name "index.html". This page will automatically be used to create your homepage. MAKE SURE TO NAME IT CORRECTLY. 
Add a link to your repository within the "index.html" file. 
    It should look something like this: <a href="https://github.com/user-name/repository-name">link to repository</a>
## 4. Commit and Push
Open VSCode and look at the menu on the left. 
There will be a tab named **Source Control**.
    Click on that tab. 
Here, any changes saved within your files will be "pushed" to the now linked GitHub repository.
You will see a drop-down menu labeled changes with any file names that been recently changed. 
    Hover over the files and locate the plus icon "+" next to the file name. 
        Click the icon when ready to stage your file changes. 
Once the icon is clicked, type a brief message in the message box to keep all changes organized for all collaborators (This includes you!)
When you are done typing out your message, click the "Commit" button.
Finally, to push these changes to your public repository press the "Sync" button that replaced the "Commit" button. 
Make sure to follow these steps with any saved changes to files that you wish to push to your newly created repository. 
## 5. Deploy Your Repository
On [GitHub](https://github.com), locate the settings menu for your repository. 
Within the settings menu, you will find a tab labeled **PAGES**.
    Click on that tab. 
Here, you want to set the source of your repository to your "Main Branch". Make sure to save. 
GitHub will now create a live URL from your "index.html" file. 
## 6. Collaboration
With the settings tab for your repository on [GitHub](https://github.com) you will find a tab labeled **COLLABORATORS**. Click on that tab. 
Here, you will be able to add collaborators to your repository freely, so long as you have a username or email. 
    Add your collaborators and have them make a "Pull" request.
